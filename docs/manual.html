    Controls guide

    Use the D-Pad, A, B, Start and Select.

    For TrimUI Brick / KNULLI. Button names refer to the Brick. This manual works offline; only external reference links need internet access.

    ButtonAction
    D-PadMove the cursor or select an item.
    AEnter/audition a note or activate a button.
    A+directionEdit a value. Left/right: small steps; up/down: large steps. Notes use semitones/octaves.
    BWith a selection: copy and end selection. While playing in PATTERN with no selection: resume following playback. In a dialog: cancel/back. Also stops audition.
    A+BCut the current field or selected block. In SAMPLE, cut selected PCM; for instrument values, restore defaults.
    Hold Select, tap BStart, expand or cancel a selection. Extend with directions in PATTERN/SONG; edit START/END with A+direction in SAMPLE. Copy with B.
    Hold B, tap SelectToggle Mute in PATTERN or the SONG channel monitor.
    Hold B, tap StartToggle Solo in the same places. Keep B held to press Select/Start repeatedly.
    Select+APaste a field, selection or Order.
    Select+left/rightSwitch between SONG–PATTERN–INSTRUMENT–SAMPLE.
    Tap SelectCancel a selection without copying. With no selection, open Actions on release.
    B+directionNavigate patterns, channel pages, instruments or samples. See the table below.
    StartSONG/PATTERN: play/stop. INSTRUMENT/SAMPLE and envelope, DRAW or CHOP editors: audition/stop.
    Select+StartFrom any main screen, play the song from Order 00, row 00. Stop if already playing.

    Using a Select combination prevents Actions from opening on release. X/Y and L/R are unused. Edit numbers and choices by holding A and pressing a direction, including in settings. Activate buttons such as APPLY and LOAD with a single A press.

    Up/down moves between rows; left/right moves within a row. Returning to a row restores its last horizontal position. Navigation stops at the ends without wrapping. Positions are remembered while the app is running.

    Quick start

    1. Choose NEW in SONG.
    2. In PATTERN, press A in the CH 01 note column, then use A+direction to change the pitch.
    3. Enter C-4 / E-4 / G-4 / B-4 at rows 00 / 04 / 08 / 0C using the default instrument 01.
    4. Press Start to loop the pattern; press again to stop.
    5. In SONG, press A on the final .. Order row to add the next pattern number, 01. To repeat the same part, use A+left in its PATTERN column to choose 00. Press Select+Start while stopped to hear the song from the beginning.
    6. Choose SAVE in SONG, then select a folder and filename.

    Only the active tab shows its number. PATTERN displays 16/32 rows and 4/8 channels per page, depending on settings. Operation messages briefly replace the cursor description in the bottom information line.

    KEY MAP: shows 96 notes, C-0–B-7, in pages of 24 rows. Choose a note with up/down and change its sample assignment by one with A+direction. A+B resets that note to sample 00. Selecting a sample alone does not change the key map.

    Add/delete Orders: press A on the final .. row to add the last pattern number plus one (up to FF). A+left/right adds the last number −1/+1; A+up/down adds +16/−16. This does not copy pattern content. Select+B and directions select a range; B copies, Select+A pastes and A+B deletes Orders. The patterns themselves remain.

    Insert an Order: SONG → Select → ORDER MANAGEMENT → INSERT ORDER inserts the same pattern number before the current Order and shifts later Orders down. Both entries share the pattern content.

    Pattern length: edit ROWS in SONG with A+direction. Shortening always requires confirmation and affects every Order using that pattern.

    Navigation and shared patterns: B+up/down moves by 16/32-row pages, then to the previous/next Order at a boundary. It keeps the relative row, entering the previous Order's last page or the next Order's first page; short pages clamp to their last row. Repeated pattern numbers still have separate Order positions. Choose an Order in SONG and press Select+right to open it. PATTERN 00* marks a pattern shared by multiple Orders: editing it changes all uses.

    Empty slots: open unused/new patterns 00–FF through Select → PATTERN LIST, or assign a number in SONG and open it. Opening from the list does not add an Order. B+direction also browses unused instruments 01–80 and samples 00–0F (hexadecimal). Empty slots are created when edited, imported or pasted into.

    Enter OFF: in a single PATTERN note field, lower C-0 once more with A+left/down to enter OFF. A+right/up from OFF returns to C-0. An octave down first stops at C-0, for example C#0 → C-0 → OFF. This does not apply to range transposition.

    Cancel selection: tap and release Select to cancel without copying. Repeated Select+B cycles through current cell → whole current column → whole pattern → cancel in PATTERN, or current range → all → cancel in SONG/SAMPLE. A separate B press copies and ends selection. This also applies to sample ranges set directly.

    Block editing: use Select+B, then directions to select rows and columns. A+direction changes only the column type under the orange cursor within the selection. Notes change by semitone left/right or octave up/down; other numbers by 1/16; effect types by 1. A plain volume cursor changes only plain volumes; a volume-command cursor changes only commands, with left/right for x and up/down for type. Empty notes and OFF remain. If a note would exceed the pitch range, the whole transpose is cancelled.

    B copy and A+B cut affect only selected columns. Select+A pastes into the same columns of the target channel, leaving other columns unchanged.

    Volume column: as in FT2, volume is 00–40 (hexadecimal, 0–64), and commands appear as -x, +x, Px, etc. In a single field, A enters a volume. A+up beyond 40 reaches the first command, -0. For commands, A+left/right edits x and A+up/down changes type. A+down from the first command returns to volume 40. The bottom line explains the current field.

    Sample ranges: edit LOOP or SELECTION START / END with A+left/right for one frame, or A+up/down for 1% of the sample length (at least one frame). END is the first frame outside the range. Moving one endpoint keeps the other fixed; nonempty ranges cannot cross or shrink below one frame. Directions alone always move focus, even after Select+B, which focuses selection END. B copies the selection; Select cancels it; A+B cuts it.

    Process a sample range: press A on PROCESS to open tools with the current range. With no selection, tools use the whole sample. LOOP FROM SELECTION makes the selected range a Forward loop; the loop type field below LOOP selects Off/Forward/Ping-pong. B returns with the range intact. Sample and instrument export commands remain in Actions.

    Envelopes: directions select a point/field; A+direction changes values. Press A on INSERT / DELETE. A+B cuts one point; Select+A pastes it. Select+left/right switches volume/panning; B closes. Use presets below to transfer a whole envelope.

    Envelope presets

    Open PRESET below the volume or panning envelope. Choose a card with directions, then A to enter its button row. Choose an action with left/right and press A. Select+left/right switches volume/panning; B returns to the envelope editor.

    • LOAD: apply to the current instrument; one Undo restores it.
    • SAVE CURRENT: store the current envelope in the selected preset slot without changing the song or Undo history.
    • RESET SLOT: after confirmation, restore that preset slot to its app default. The current instrument stays unchanged until you LOAD it.

    Up from the button row returns to the selected card. Pressing A again restores the last button. Navigation stops at the ends without wrapping.

    Volume presets include points, On/Sustain/Loop, Fadeout and auto Vibrato. Panning presets contain only the panning envelope. The other envelope, PCM, key map and name stay unchanged. To transfer an envelope between instruments, SAVE CURRENT at the source and LOAD at the destination.

    Preset slots persist across restarts independently of songs. The six defaults per bank are app-created shapes, not exact FT2 factory presets. If the preset file cannot be read, the app keeps it, shows a warning and uses defaults.

    Waveform drawing

    Open DRAW in SAMPLE to edit the selected range, or the whole sample if none. The waveform has no separate focus. Left/right moves between points from either VALUE or EDIT POINTS; Select+left/right takes larger steps. In VALUE, A+left/right adjusts amplitude finely, A+up/down coarsely, and A+B sets the point to zero.

    Up/down moves between fields and the button row. In EDIT POINTS, use A+direction to choose 8/16/32/64 or FRAME. SMOOTH spaces edit points evenly on the graph without moving their PCM frames. FRAME edits individual frames; FRAME and SAMPLE use actual frame spacing. In the button row, left/right selects NEW WAVE / CLEAR ALL / APPLY; up returns directly to EDIT POINTS. Returning down restores the last button. CLEAR ALL zeros the entire sample draft, including frames outside a selection, while keeping its length, loop and tuning.

    DRAW in an empty slot, or NEW WAVE, offers SINE / TRIANGLE / PULSE / SAW / NOISE. Choose a shape and press A to reach its options. Up/down changes rows; left/right selects within a row, remembering the last column when you return. A+left/right changes a value finely; A+up/down takes larger numeric steps. Tone shapes have FRAMES (16/32/64/128/256). PULSE adds DUTY (12.5/25/50/75%); SINE, TRIANGLE and SAW add LEVELS (16/256 amplitude levels).

    NOISE uses TYPE: SHORT is a tonal 127-frame sequence; LONG is a noisier 32767-frame sequence. Both keep a complete repeating noise period. Noise hides tone length, levels and phase controls.

    • DRIVE is gain before processing; it does not change the sample's playback volume setting. DIST chooses OFF / CLIP / FOLD / WRAP. LIMIT appears when distortion is on and sets its amplitude boundary. VSHIFT shifts the waveform vertically before distortion.
    • FILTER offers OFF / LOWPASS / HIGHPASS / BANDPASS / ALLPASS. When enabled, CUTOFF sets frequency as a percentage of the generated sample's Nyquist frequency; Q sets resonance. ALLPASS changes phase rather than bypassing processing.
    • PHASE chooses PINCH / WARP / RESYNC / RESYN2; AMOUNT controls the horizontal reshaping, with zero leaving timing unchanged. RESYNC reduces aliasing; RESYN2 keeps the raw resynchronised shape. These are app-generated shapes, not exact LSDj emulation.

    Changing an option regenerates from the original shape. CREATE returns to DRAW with the exact preview as an 8-bit loop draft; reduced levels do not constrain later drawing. Noise starts in FRAME editing. B in the creation dialog preserves your existing draft. XM stores the resulting PCM, not the generator settings; filtering and shaping are baked into that one sample.

    Press Start in NEW WAVE or DRAW to toggle draft listening. While LISTENING, shape, option and waveform changes retrigger the current preview without saving. CREATE keeps listening; B, APPLY or losing focus stops it. If a song is playing, the first Start stops the song; press Start again to listen to the draft.

    NEW WAVE replaces the entire sample draft. The original changes only on the final APPLY; B in DRAW cancels editing. Start in SAMPLE auditions the applied sample.

    Playback & audition

    • Start while stopped: SONG plays from the selected Order's first row. PATTERN loops the selected rows, or the whole current pattern from its first row if no selection. INSTRUMENT and SAMPLE audition their current sound.
    • Start or Select+Start while playing: stops. Holding B first makes Start a Solo command. The next Start begins again according to the current screen.
    • Follow: follows playback in 16/32-row pages. In PATTERN, moving between columns/channels with left/right or B+left/right keeps follow active. Moving between rows/patterns, editing or selecting pauses follow. While playing in PATTERN with no selection, tap B to resume follow without restarting playback. With a selection, B copies and ends it; tap B again to resume follow.

    Changing screens alone does not change the playback range. The SONG timer shows elapsed time since this playback started, counting from 00:00 even when starting mid-song. Per-channel waveforms, notes and levels appear below in SONG.

    Loop a selection: in PATTERN, Select+B → directions to select rows → Start. All channels in those rows loop. The cursor and selection stay in place for editing. Cancelling the selection with Select leaves the loop active until playback stops. The top shows PLAY LOOP and the bottom shows the loop rows. Use Mute/Solo to silence other channels.

    Select+Start while stopped: from any main screen, starts the whole song at Order 00, row 00. An existing selection stays in place but does not limit playback; follow stays paused while that selection is active. Selection loops started with plain Start do not restore notes or effect state from earlier rows.

    Note audition: pressing A in an empty note field enters and displays the note immediately. While stopped, pressing A on a PATTERN note or editing it with A+direction follows SETTINGS → NOTE AUDITION. The default NOTE ONLY plays that note; WHOLE ROW applies all channels and effects in the current row once. Sound plays while A is held and stops immediately on release, with no key-off release tail. A sample or envelope may finish sooner. Row audition does not advance or repeat, and follows Mute/Solo. It does not restore earlier sustained notes or effect state. During song/pattern playback, note entry and editing do not add a separate audition.

    Start audition: in INSTRUMENT and either envelope editor, hear the current instrument at the selected note, including its key map and envelopes. In SAMPLE, hear the selected PCM range or the whole sample; the waveform shows its playback position. NEW WAVE/DRAW plays the draft, and CHOP plays the current built slice. Press Start again to stop; releasing A does not stop listening. Committed instrument, sample or envelope edits retrigger the updated sound. A finished one-shot restarts with one Start press. Leaving the editor, B or losing focus stops audition. If the song is playing, the first Start stops it; press Start again to audition. Pitch detection retains its LISTEN SOURCE button.

    The top BPM shows the current playback value, or the song's initial value when stopped. L/R meters show final output, including note/sample audition. The right indicator stays red briefly after clipping.

    Channel Mute/Solo: on the current PATTERN channel or SONG channel monitor, hold B, tap Select for Mute or tap Start for Solo. Keep B held and release/repress Select or Start to repeat; holding the second button does not repeat automatically. Hold Select, tap B for range selection. In SONG, move down from the file buttons into the monitor, choose a channel with directions, and return upward from its first row.

    Solo enables only the chosen channel regardless of previous mutes. Toggling Solo again on that channel enables all channels. Muting during Solo toggles that channel from the currently audible state and clears Solo. Opening a file or creating a song enables all channels. Mute/Solo is excluded from XM saves and WAV rendering.

    Delete one slot: after confirmation, clear its content without shifting numbers. Patterns keep their length and Order references. Instruments clear their key map, settings and samples, but pattern instrument numbers remain. Deleting a sample in SAMPLE MANAGEMENT keeps the key map. All can be undone.

    Whole-slot copy/paste: COPY in Actions immediately opens a destination list, including empty slots. Choose with up/down, jump 16 with A+up/down, then A to paste. B cancels without changing the document or original cursor. Occupied slots require overwrite confirmation; cancelling returns to the same list. After applying, you edit the destination. Undo restores the change.

    Sample destinations: B+left/right chooses the parent instrument 01–80; select sample 00–0F. You return to the INSTRUMENT or SAMPLE screen where copying began. Instrument copy includes name, key map, envelopes, all settings and samples. Sample copy includes PCM, name, loop, tuning, volume and panning. Pasting a sample keeps the destination instrument's key map.

    To reuse a copy, choose the destination and run PASTE from Actions. Whole-slot copy/paste has no dedicated shortcut; block editing shortcuts remain.

    Whole-pattern paste: replaces row length, all channels/columns and empty cells, ignoring the cursor and masks. Every Order using that pattern is affected. The copied and current song channel counts must match. SONG's DUPLICATE PATTERN gives only the selected Order a new copy. It reuses gaps first, preserving patterns used by other Orders, containing data or having a custom row length. With no empty number available, nothing changes.

    Block editing and masks: B copy / Select+A paste still apply to pattern and sample ranges; selecting all is also block editing. Pattern masks affect block paste only. A+right/up enables a column; A+left/down disables it. Only columns enabled in both COPY and PASTE are pasted. RESET MASKS restores defaults.

    Swap: swaps content only. Instrument swaps leave pattern instrument numbers unchanged; sample swaps leave key-map sample numbers unchanged.

    PCM tools: for Mix, first copy PCM with Select+B → B. Crossfade needs a selection crossing a Forward loop's start and corresponding PCM one loop-length later. Morph overwrites slots between two endpoints with matching length, tuning and loops. Expand/Shrink does not adjust BPM, Speed or effect values automatically.

    Minimise: trim PCM after the loop

    Removes only PCM after an active loop's end to reduce size. It ignores selections and does not detect silence. Disabled loops and samples already ending at the loop end remain unchanged.

    • Current sample: SAMPLE → PROCESS → MINIMISE SAMPLE, immediately after Trim.
    • Current instrument: INSTRUMENT → Select → INSTRUMENT MANAGEMENT → MINIMISE INSTRUMENT.
    • All instruments: SONG → Select → PROJECT → MINIMISE ALL INSTRUMENTS, including unused instruments.

    Review the sample count and saved XM PCM bytes, then A to apply or B to cancel. Each 8-bit frame uses one byte; each 16-bit frame uses two. One Undo restores the whole operation. Cancelling or finding nothing to trim leaves the song and history unchanged. Numbers, key maps, loop positions, tuning and envelopes are preserved.

    Detect sample pitch

    SAMPLE → PROCESS → ADVANCED PCM → DETECT PITCH

    Analyzes the selection, or the whole sample if none, and shows the pitch heard at C-4 with the current tuning. Review the note/deviation and audition with LISTEN SOURCE. APPLY TUNING adjusts Relative Note and Finetune so C-4 sounds at C-4.

    Best for steady, single-note audio around 50–2500 Hz at C-4 playback. Drums, noise, chords and changing pitch can be unreliable; results cannot be applied without sufficient confidence. Analyzing a selection still retunes the whole sample. PCM, loops and pattern notes remain unchanged, and Undo restores tuning. Import does not apply pitch detection automatically.

    For short single-cycle waves, a range exactly matching the active Forward loop is repeated for analysis. Partial selections and Ping-pong loops are not extended this way.

    Chop a sample

    SAMPLE → PROCESS → ADVANCED PCM → CHOP SAMPLE

    1. Choose 1–16 slices for the whole sample or selection. EQUAL divides as evenly as possible; ATTACK SNAP shifts boundaries to nearby attacks, so lengths may differ.
    2. Set DESTINATION to NEW or CURRENT. NEW uses an empty instrument; CURRENT fills slots without PCM. CURRENT remains available even if a new instrument is available.
    3. Press BUILD PREVIEW to create a boundary draft. Choose the current chunk with SLICE. In CUT FRAME, A+left/right moves its right boundary by one frame; A+up/down moves by 1% of the selected range, with a minimum of one frame. The final endpoint is fixed.
    4. ADD CUT splits the selected slice at its midpoint; then adjust CUT FRAME. REMOVE CUT merges it with the next slice without losing PCM. Keep 1–16 nonempty slices. REBUILD PREVIEW replaces manual cuts with automatic boundaries.
    5. Press Start to audition the selected slice, and again to stop; the waveform shows the actual playback position. Changing the selected slice or a cut stops the previous audition. Only APPLY CHOP changes the document or source PCM; one Undo restores it. B cancels the draft.

    Up/down moves between rows; left/right selects items in the same row. Returning to a row restores its last column, and navigation does not wrap. Use A+direction to change a field.

    If the current instrument lacks enough empty slots, confirm replacement of the whole instrument. Confirming replaces its samples, key map and envelopes with the sliced instrument; cancelling preserves them. Using a new instrument or empty slots keeps the source sample.

    If no empty instrument is available, NEW stops without changing the document. You can still choose CURRENT.

    Slices map to consecutive notes from C-4, with tuning adjusted to preserve their original speed and pitch. Loops are disabled. Filling current empty slots keeps existing envelopes and other samples; a new/replaced instrument starts with default envelopes.

    After applying, INSTRUMENT → INSTRUMENT MANAGEMENT → EXPORT XI saves up to 16 slices and their key map in one XI file.

    Files, saving & recovery

    File browser: up/down: one entry; left/right: 15 entries; A: open/select; B: cancel. Select is unused. Press A on ../ to go up; the cursor selects the folder you just left. When saving, Start opens filename entry. To delete a character, choose the on-screen DEL and press A.

    Default folders: the ZIP includes empty songs/ (XM and song WAV renders), instruments/ (XI), samples/ (sample audio), themes/ and userdata/ folders beside the executable. Settings and recovery data live in userdata/. Only userdata/ and themes/ are created on launch if missing; removed content folders stay removed.

    OpenMPT files: compact XM headers are supported. An import notice appears when OpenMPT extras are skipped. Comments, MIDI settings, extra names and extended properties are not applied or saved; playback that depends on OpenMPT-specific settings may differ. Use SAVE AS to keep the original file.

    Choose each location under SETTINGS → DEFAULT FOLDERS → SONGS / INSTRUMENTS / SAMPLES. The picker lists directories only: A opens a folder, Start selects the current folder, B cancels back to settings; Select is unused. Choices persist across restarts and apply to both load and save/export dialogs. Browsing elsewhere does not change them. If a chosen or packaged default folder is missing or unreadable, the dialog opens beside the executable without creating the path or clearing the preference; it uses the chosen path again when available.

    SAVE AS uses the chosen song folder; SAVE on an existing song writes to its original XM path. Existing files are not moved or deleted when choosing folders. Theme files use only the fixed themes/ folder.

    • SONG SAVE / SAVE AS / LOAD / NEW: save the current XM / save under another name / open XM / create a song.
    • Audio LOAD: choose WAV, FLAC, MP3 or Ogg Vorbis → set CHANNEL MIX (Blend/Left/Right) and BIT DEPTH (8/16-bit) with A+direction → IMPORT. Replaces the current sample.
    • CLEAN UP PATTERNS: in SONG → PROJECT, clears only patterns not used by any Order. Keeps instruments.
    • CLEAN UP INSTRUMENTS: in the same menu, clears instruments not referenced by any pattern. Keeps instruments used by unplaced patterns and samples belonging to retained instruments. To clean both, clean patterns first. Each operation shows a deletion count for confirmation and can be undone.
    • EXPORT SAMPLE WAV: in SAMPLE MANAGEMENT or PCM PROCESSING, choose WHOLE SAMPLE or SELECTED RANGE. To preserve the selection, use SAMPLE's PROCESS button, or A during Select+B range selection. Ranges include the first frame and exclude the end frame. Empty ranges cannot be exported.
    • RENDER WAV: in SONG → PROJECT, set SCOPE to the whole song or an Order range. For a range, set FIRST ORDER / LAST ORDER, including the last Order. Set MAX DURATION / TAIL / TOTAL PASSES, then CHOOSE FILE to render 16-bit stereo WAV. Uses the applied rate (44.1/48 kHz) and interpolation from SETTINGS → AUDIO OUTPUT. Ranges use song Orders, not arbitrary rows.
    • RECORD MICROPHONE: choose a device and time limit → START RECORDING. A finishes and asks to replace the sample; B discards.

    Sample WAV versus song rendering: sample WAV exports the raw waveform as 16-bit mono. Its rate is the C-4 playback rate with Relative Note and Finetune applied. It omits instrument envelopes, song effects and sample loop metadata. Saving or cancelling leaves the sample, loop, selection and edit history unchanged.

    Order-range rendering: starts at row 0 of the first Order with initial state, without restoring earlier sustained notes or effects. It follows jumps/loops within the range until first leaving it or reaching song end, completing one pass. TOTAL PASSES sets the repeat count; Tail is added only once at the end. Internal infinite loops are capped by the maximum duration; reaching it reports a partial WAV.

    Recovery: changed work is saved to two recovery slots roughly every 30 seconds and on exit. On restart, the newest valid candidate is used; if damaged, the previous valid slot is used. Recovery does not overwrite your working XM file.

    Explicit save: press SAVE when ready. Overwriting an XM keeps one previous file in the sibling Backup folder. UNSAVED means changes have not been explicitly saved.

    Settings & mapping

    Open Select → SETTINGS from any tab. Edit values with A+direction; press A to open a submenu. Settings persist across restarts.

    • PATTERN VIEW: 4/8 channels.
    • PATTERN ROWS: 16/32 rows per page; actual pattern length stays unchanged.
    • ROW NUMBERS: DEC (000–255) / HEX (00–FF). Channel numbers are decimal 01–32.
    • NOTE AUDITION: preview when pressing A on a PATTERN note or editing its pitch. A+left/down sets NOTE ONLY (default); A+right/up sets WHOLE ROW, saved immediately.
    • DEFAULT FOLDERS: separate song, instrument and sample locations; see Files, saving & recovery.
    • Fullscreen and direction-repeat delay/interval.

    Pattern display and audition use the same SETTINGS menu and save immediately. These are app settings, shared across songs and restarts.

    Theme colors

    From any tab, open Actions → SETTINGS → THEME COLORS. On COLOR, use A+direction to choose one of 13 color roles. Edit each RGB value with A+Left/Right for steps of 1 or A+Up/Down for steps of 16, and check the preview.

    LOAD THEME loads a .theme file into the draft preview; choose APPLY to use it. The fixed themes/ folder beside the executable holds 28 presets: Default, Midnight, Amber, Mono, Ocean, Forest, Phosphor, Cobalt, Arcade, Ember, Ice, Lavender, Rose, Copper, Sand, Paper, Paper Orange, Ink Orange, Game Boy, Pocket, LCD Blue, LCD Silver, LCD Champagne, LCD Sage, LCD Lilac, Pastel, Pink Sky and Sky Candy. On launch, missing presets are copied from assets/themes/; existing files are kept. The picker stays in this folder, with no parent navigation or custom path.

    SAVE THEME exports the current draft: choose NEW THEME... to enter a name, or select an existing file and confirm overwriting. Saving a theme file does not apply it or change the song or app preferences. B cancels the picker. To share a theme, copy its .theme file into another installation's themes/, then LOAD THEME and APPLY.

    RESET COLOR and RESET ALL change the draft. Only APPLY saves the active theme across restarts; B in the editor discards the draft. Active colors live in userdata/editor-settings.txt, separate from XM files, recovery and Undo/Redo history. The theme editor uses fixed colors to keep its controls readable.

    Audio output

    Open AUDIO OUTPUT, choose OUTPUT RATE (44.1 / 48 kHz) and INTERPOLATION. Defaults are 48 kHz / Linear. APPLY stops playback and audition, then applies changes. B before applying discards them.

    Interpolation calculates values between PCM points when playing samples at different pitches.

    MethodBehavior
    NearestUses the nearest value. Low CPU cost, rougher sound.
    LinearA straight line between two points. Default.
    Cubic Lagrange / Cubic SplineDifferent curves using four points.
    Sinc / Sinc PreciseUses multiple nearby PCM values. Precise covers more points and costs more CPU.

    Each method uses ramping to reduce clicks from sudden volume changes. Settings affect song playback, instrument/sample audition and song WAV rendering. Original PCM, tuning, sample WAV exports and microphone input stay unchanged.

    Change the song's actual channel count in SONG's CHANNELS and pattern length in the Order's ROWS field. Names have basic multilingual display; text entry is mainly English letters and numbers. App menus are in English.

    There is no in-app controller mapping menu. For other devices, place their SDL2 mappings in gamecontrollerdb.txt beside the executable. SDL calls Select back. See the SDL2 mapping format.

    Brick installation

    1. Extract the Brick/KNULLI ARM64 ZIP.
    2. Copy roms/ports/Little XM Tracker.sh and roms/ports/xm-tracker/ into KNULLI SHARE's roms/ports.
    3. Refresh the game list, then launch Ports → Little XM Tracker.

    The ZIP includes empty songs/, instruments/, samples/, themes/ and userdata/ folders. On launch, the app creates userdata/ and themes/ if needed and copies missing theme presets and the editable gamecontrollerdb.txt from assets/; existing files are kept. Removed song, instrument and sample folders are not recreated.

    Updating: copy the whole new distribution over the existing installation, merging folders and overwriting matching application files. Do not delete or replace the existing xm-tracker/ folder first. The ZIP contains no files in the five user folders and no root mapping file, so your content and settings stay in place. For launch issues, include your KNULLI version and userdata/launcher.log.

    When updating an older version, rename XM Tracker.sh to Little XM Tracker.sh.
